# Контур данных и границы прототипа

В runtime аудио декодируется локально; Whisper и pyannote загружают только заранее подготовленные файлы. Hugging Face offline-флаги и отключение телеметрии задаются до импорта моделей. Языковая модель вызывается через Ollama; публичные URL запрещены, HTTP proxy окружения игнорируется. Это защита от случайной конфигурации, не замена сетевой изоляции: localhost/DNS и хосты Docker должны контролироваться администратором. На сервере запретить исходящий трафик на уровне firewall. В Compose сеть internal.

Подготовка пакетов/весов требует отдельного сетевого этапа без записей совещаний. Затем контейнеры, пакеты и веса переносятся в закрытый контур. Экспорты и аудио не отправляются почтой или в мессенджеры.

По умолчанию API слушает 127.0.0.1, интерфейс рассчитан на одного доверенного пользователя. Для сетевого доступа обязателен GESTSPEAK_API_TOKEN, TLS через внутренний reverse proxy, ограничение Origin и правила доступа. Токен вводится в настройках интерфейса и хранится только в памяти вкладки. Полноценные SSO/RBAC, разграничение совещаний по пользователям, шифрование БД, защищённое стирание и юридически значимая подпись не реализованы.

Записи сохраняются в data/audio, протоколы — в SQLite. Каталог данных исключён из Git. Удаление совещания удаляет запись и строки БД, но не гарантирует физического стирания из WAL, SSD и резервных копий. Журнал фиксирует тип события и время, без текста транскрипта. Это операционный журнал, не неизменяемый аудит.

Ограничения: 250 МБ на файл, 2 часа декодированной записи, один worker и четыре задания в очереди. Проверка длительности выполняется после декодирования; для враждебных файлов нужен sandbox worker и лимит памяти контейнера. При перезапуске незавершённые задания помечаются ошибкой, повторная загрузка явная. Удаление выполняющегося задания запрещено.

Транскрипт — недоверенные данные: системная инструкция модели запрещает выполнять содержащиеся в нём команды. Выход проходит Pydantic-валидацию, проверку цитат/ID реплик, детерминированный пересчёт срока и ручное подтверждение. Эти меры снижают риск, но не устраняют prompt injection или семантические ошибки модели. Наличие цитаты само по себе не доказывает верность поручения.
