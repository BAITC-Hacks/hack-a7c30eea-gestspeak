## Интерфейс и запуск

`npm run typecheck` и финальная производственная сборка `npm run build` выполнены успешно. Сборка сформировала статический маршрут `/` для обслуживания из FastAPI. После перезапуска текущая версия интерфейса отвечает HTTP 200 с того же сервера, что и API.

Скрипты установки/запуска прошли `bash -n`, `compose.yaml` — синтаксический разбор YAML, shell-команда подготовки Ollama — `sh -n`. Проверены относительные ссылки Markdown и `git diff --check`. `.env`, `.env.production`, `frontend/.env.local` и `.venv-ai` исключены из Git; варианты `.env` также исключены из Docker build context.

Docker не установлен на машине проверки, поэтому сборка и запуск контейнеров здесь не заявляются. Встроенный браузер среды разработки недоступен: интерактивный браузерный прогон и визуальный рендер PDF/DOCX не засчитаны. Экспорты проверены программно.

## Аудио и качество моделей

Репозиторий содержит полный локальный адаптер Whisper + pyannote + Ollama и облегчённый CPU-профиль Whisper tiny + sherpa-onnx. Подготовка весов отделена от обработки встреч. Для полного профиля pyannote владелец самостоятельно принимает условия модели.

Автоматическое распознавание RU/KK/mixed, DER и точность назначений требуют независимой проверки на аудиоданных. Технический прогон короткой синтетической записи проверяет запуск компонентов; он не является языковым бенчмарком. Метрики WER/CER, DER, precision/recall/F1 поручений и точность исполнителя/срока не публикуются без размеченного набора и измерений.

Ollama/Qwen2.5 и полный GPU-профиль не проверены на целевом сервере. При недоступной LLM интерфейс явно показывает режим локальных правил и оставляет поручения черновиками.
