# Проверка прототипа

Проверено 23 сентября 2026 на macOS, Python 3.9.6, Node 24.18.

- 17 unit/API тестов: даты RU/KK, календарные недели, воскресенье на казахском, отсутствие догадок в полях исполнителя/срока, слова на границах голосовых интервалов, запрет внешнего LLM endpoint, явные поручения RU/KK/mixed, эталон из 10 поручений, PDF и DOCX, API persistence, Origin и token auth.
- Живой API: два отдельных протокола из `kazakh.txt` и `mixed.txt`, по два явных поручения, состояние `ready`, явно указан режим `rules`, последующее удаление.
- TypeScript: `npm run typecheck`.
- Production build: `npm run build`, статический экспорт маршрута `/`.
- Сервер статического интерфейса отвечает HTTP 200 на `http://127.0.0.1:8000/`.

Не проверены: распознавание реального аудио локальными весами, качество RU/KK/code switching, реальная диаризация, извлечение локальной LLM, Docker/GPU на сервере заказчика, визуальный рендер DOCX/PDF и интерактивный браузерный прогон. PDF/DOCX проверены структурно и на наличие кириллицы/казахских букв. Встроенный браузер среды разработки оказался недоступен, поэтому визуальная проверка интерфейса не заявляется. WebMCP зарегистрирован как необязательное расширение навигации, доступного контекста для проверки нет.

Причина ограничения полного AI прогона: на исходной машине не установлены веса, мало свободного диска и 8 ГБ RAM; модель pyannote также требует принятия условий доступа владельцем. В репозиторий включены адаптеры, версия зависимостей, подготовка моделей и инструкция; заранее размеченный пример не используется для заявления точности.
