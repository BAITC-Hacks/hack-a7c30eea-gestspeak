# Демонстрация GestSpeak — 3 минуты

Откройте **http://127.0.0.1:8000** до начала выступления. Подготовьте вкладку с README и папку для скачанных документов.

## Если есть ещё одна минута

Создайте новое совещание из `examples/mixed.txt` или кнопкой mixed, выберите дату и подтвердите уведомление участников. Покажите, что результат создаётся из нового текста. Если работает режим правил, обозначьте это: поддерживаются отдельные формулировки и уточнения, но правила не заменяют контекстную LLM.

Кнопка «Открыть демопример» — запасной путь для показа интерфейса. Это заранее размеченный эталон из десяти поручений; обязательно назовите его демонстрационным, если используете вместо нового анализа.

Аудио показывайте только после успешного прогона на том же компьютере. Загрузите короткую синтетическую запись, после распознавания сопоставьте голосовые кластеры с именами и проверьте цитаты. Не выдавайте заранее размеченный эталон за результат модели.

## Контроль перед выступлением

1. Приложение открывается; в «Система» виден актуальный статус моделей.
2. Создано отдельное тестовое совещание RU/KK/mixed и проверено конечное состояние.
3. PDF/DOCX открываются, кириллица и казахские буквы читаются.
4. Для демонстрации используется синтетическая либо анонимизированная запись.
5. Ссылка на репозиторий, README и история коммитов доступны жюри.

## Ответы на вопросы жюри

**Почему локально?** Кейс запрещает передачу аудио и текста внешним облачным API. Подготовка весов происходит отдельно от обработки встреч.

**Как справляетесь с ошибками?** Сохраняем источники, проверяем схему и сроки, оставляем результат черновиком до подтверждения человеком. Неизвестные имя и дата остаются пустыми.

**Чем отличаетесь от транскрибатора?** Сквозной цикл: разговор → проверяемое поручение → исполнитель и срок → статус → контроль исполнения → документ.

**Что ещё предстоит?** Измерение качества RU/KK/mixed на независимых записях, полноценные роли доступа, бот-участник конференций и СЭД. Эти возможности не заявляются как уже реализованные.
